### 1.3 Postman

1. Postman → **Import** → 위 컬렉션 파일 → **Variables**에서 `baseUrl`과 계정 id 확인
2. **Run** → 0번 폴더부터 순서대로. 앞 요청이 다음 요청의 id를 변수에 담아요
3. 다시 돌릴 때도 0번부터 (새 공연이 생겨요). 5번 폴더의 신고는 같은 대상이면 처음 번호가 그대로 와요

- **CSRF**: 계정 전환이 쿠키 `csrf_token`을 `csrfToken` 변수에 담고, 쓰기 요청 42개가 `X-CSRF-Token`으로 보내요 (계정 전환 18개는 CSRF 검사에서 빠져 있음).
- **멱등 키**: 결제·확정·다음 단계는 사전 스크립트가 새 `Idempotency-Key`를 만들어요. `3-12`는 `3-11`과 같은 키를 일부러 다시 보내요.
- **바뀌는 데이터**: 공연 1개, 견적서 2개, 청구서·결제·장부, 취소, 신고 1건이 남아요. 시연 DB 말고 시험용 DB에서 돌려요.
