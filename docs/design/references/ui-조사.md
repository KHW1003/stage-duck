# 국내 서비스 UI 조사 (2026-11-16)

목업 v2를 다듬기 전에 국내 주요 서비스의 첫 화면을 직접 열어 화면 값을 재 봤어요. 22곳을 열었고, 네이버는 브라우저 도구의 안전 제한으로 열지 못했어요.

- 방법: 1280px 폭으로 열고, 화면에 보이는 요소의 글꼴·글자 크기·글자색·모서리·그림자·테두리 값을 스크립트로 세었어요 (가장 많이 쓰인 값 3개).
- 한계: **첫 화면만** 봤어요. 예매·결제·마이페이지 같은 안쪽 화면은 로그인이 필요해 보지 못했어요. 티켓링크·캐치테이블은 화면이 늦게 그려져 값을 못 쟀어요.
- 저작권: 로고, 사진, 그림, 문구, 고유한 아이콘, 색 조합 전체, 화면 배치 통째는 가져오지 않았어요. 가져온 것은 **모서리 크기, 글자 단계, 선·여백 쓰는 법처럼 여러 서비스가 함께 쓰는 일반적인 방식**뿐이에요.

## 함께 보이는 것

1. **글꼴은 Pretendard.** 22곳 중 12곳. 우리도 이미 쓰고 있어요.
2. **그림자를 거의 안 써요.** 값을 잰 20곳 중 14곳이 0개. 우리 규칙(DESIGN.md 8장)과 같아요.
3. **상자 모서리는 8~12px.** 0px은 오래된 티켓 사이트와 패션 쇼핑몰이에요. 우리 6px은 그 사이라 어중간했어요.
4. **글자색은 2단계.** 거의 검정(#1b~#22) + 회색 하나. 푸른 기가 도는 회색은 숨고·와디즈 정도예요.
5. **본문은 14~16px.** 우리는 14 · 13 · 12 · 11이라 한 단계 작았어요.
6. **테두리 상자가 적어요.** 구역은 선보다 여백으로 나누고, 테두리는 입력칸·고를 수 있는 칸에만 써요.
7. **색은 주조색 하나.** 버튼과 지금 고른 것에만 쓰고, 나머지는 검정·회색이에요.

## AI가 만든 것처럼 보여서 덜어낸 것

- 구역 제목마다 붙인 아이콘
- 요약 칸마다 넣은 네모 아이콘 상자
- "~을 찾으세요?", "지금 ~하고 있어요" 같은 문장형 큰 제목
- 둥근 회색 상자, 동그란 아이콘이 줄지은 기록, 알약 라벨
- 똑같은 모양의 칸 3개를 나란히 놓는 배치의 남용
- 색을 여러 곳에 흩어 쓰는 것 (제목·금액·아이콘에 모두 빨강)

## 적용

- `docs/design/mockup-v2/css/refine.css`에 모았고, 대표 화면 6개에 먼저 걸었어요: 내 공연, 견적함, 단계별 비교, 통합 청구서, 공고 목록(업체), 거래 이력(v4 시안).
- 머리(GNB)와 바닥글은 그대로예요.
- 팀이 확정하면 `tokens.css`와 공통 CSS에 합치고 나머지 화면에도 넓혀요. DESIGN.md의 모서리·글자 크기 값도 그때 고쳐요.
