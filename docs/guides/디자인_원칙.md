# 디자인 원칙 — AI가 만들지만 AI스럽지 않게

사용자·업체 화면(React)의 디자인 기준이다. 관리자 화면(SQLAdmin)은 [관리자 테마](../../backend/app/admin/static/admin.css)를 따른다.

이번 프로젝트는 **목업(Figma)을 만들지 않는다.** 화면은 대부분 Claude가 만든다. 기준이 없으면 AI는 가장 흔한 평균값(보라 그라데이션, 둥근 카드 3열, 반짝이 아이콘…)을 골라 어느 서비스에 붙여도 같은 화면을 만든다. 그래서 **사람이 방향과 선택을 정하고, AI는 그 규칙대로 실행한다.**

## 2. 방향: 공연 현장 도구

> 화면은 **무대 감독의 클립보드**다. 예쁘게 보이는 것보다 **한눈에 읽히고, 틀린 것이 바로 보이는 것**이 먼저다.

- 사용자는 공연을 준비하는 사람(밴드·극단·교회·학원)이고, 업체는 현장 사람이다. 둘 다 **시간·금액·누가 무엇을**을 확인하러 온다.
- 기본은 **라이트 모드** — 종이 큐시트처럼 따뜻한 흰 바탕에 잉크색 글자. (관리자 화면만 다크 기본)
- 장비를 모르는 사람도 읽을 수 있게 **쉬운 한국어**로 쓰고, 전문 용어는 처음 나올 때 풀어 쓴다.

## 3. 큐시트에서 가져온 규칙

| # | 규칙 | 화면에서 |
|---|---|---|
| R1 | **시각 열**: 시간이 있는 정보는 왼쪽에 시각(고정폭 숫자), 오른쪽에 내용 | 일정, 최종 담당표, 채팅의 시각 |
| R2 | **구간은 선으로**: 카드·그림자 대신 가로선. 큰 구간은 굵은 잉크선, 작은 구간은 얇은 선 | 모든 목록·상세 |
| R3 | **글자로 위계**: 크기·굵기·회색 단계로만 구분. 배경색 상자는 꼭 필요할 때만 | 제목·본문·보조 글자 |
| R4 | **장식 없음**: 아이콘은 뜻이 있을 때만(상태, 행동). 일러스트·이모지 없음 | 전체 |
| R5 | **숫자는 고정폭, 오른쪽 정렬, 단위와 함께**: `500,000원`, `120분`, `80명` | 금액, 시간, 인원 |
| R6 | **한 줄에 한 항목**: 한 줄에 다 읽히게. 줄이 넘치면 내용을 줄인다 | 목록, 표 |
| R7 | **상태는 짧은 글자로**: "확정", "모집 중", "건너뜀" + 작은 점. 색은 글자를 돕는 보조 | 단계, 견적, 검사 결과 |
| R8 | **메모는 그 줄 옆에**: 문제가 있는 줄 바로 옆에 이유를 적는다 (따로 모아 두지 않는다) | 자동 검사 결과 |

## 4. 우리만의 시각 언어 (STAGE DUCK에만 있는 것)

| 요소 | 표현 |
|---|---|
| **셋리스트 단계 표시** | 공연장 → 장비 → 엔지니어를 셋리스트처럼 번호 붙인 목록으로: `01 공연장 — 확정 · 공연장 C` / `02 장비 — 모집 중` / `03 엔지니어 — 대기`. 지금 단계만 주황 |
| **큐시트 일정** | `15:00 입실` · `15:00–15:45 장비 설치` · `17:00 리허설` · `19:00–21:00 공연` · `21:00–22:00 철수` 를 시각 열 + 가는 막대로. 검사 결과는 해당 줄 옆 메모(R8) |
| **주황의 뜻은 하나** | 주황(`#FA4F00`, 로고 색)은 **"지금 / 해야 할 일"**에만: 현재 단계, 주 버튼, 선택된 것. 한 화면에 **두 곳 이하**. 장식에 쓰지 않는다 |
| **잉크색** | 글자·굵은 선은 로고 오리의 검정(`#1C1716`) 계열. 순수 검정 `#000`은 쓰지 않는다 |
| **로고** | 기타를 든 오리. 헤더 왼쪽에 작게 한 번만. 화면 안에서 오리를 반복해 쓰지 않는다 (마스코트 남발 금지) |

## 5. AI스러움 금지 목록

화면을 만들 때 **하지 않는다.** CLAUDE.md 6.2에도 같은 목록이 있다.

1. 그라데이션 (배경·글자·버튼 모두). 특히 보라·파랑 계열
2. 그림자로 띄운 카드, 유리처럼 비치는 효과(glassmorphism), 흐림 효과
3. 같은 크기 둥근 카드를 3열·4열로 늘어놓기 — 목록은 줄(R6)로
4. 이모지, 반짝이(✨) 아이콘, 장식용 아이콘, 일러스트, 3D 그림
5. 큰 그라데이션 제목이 있는 히어로 영역, 의미 없는 배경 도형
6. "손쉽게", "혁신적인", "한 번에 해결", "~의 모든 것" 같은 광고 문구 — 명세서의 실제 문구를 쓴다
7. 가짜 숫자·가짜 후기·가짜 로고 띠 ("10,000+ 업체", "★★★★★") — 시연 데이터만 쓴다
8. 모든 제목·항목 앞에 아이콘 붙이기
9. 강조색 여러 개, 상태마다 진한 배경 배지 — 강조색은 주황 하나, 배지는 글자 + 작은 점
10. 모서리를 크게(16px 이상) 둥글리기, 모든 것을 알약 모양으로
11. 의미 없는 애니메이션(떠오르기, 반짝임, 숫자 굴러가기)
12. 가운데 정렬 남발 — 기본은 왼쪽 정렬, 숫자는 오른쪽 정렬
13. 빈 공간을 채우려고 넣는 장식, "Coming soon" 카드
14. lorem ipsum, "홍길동", "테스트 업체" 같은 가짜 텍스트 — 시연 데이터(공연장 C, 장비 D…)를 쓴다
