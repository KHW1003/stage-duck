# Claude 사용법 — 토큰을 아끼는 세션 쓰는 법 (사람용)

> AI가 따르는 규칙은 `CLAUDE.md`에 있다. 이 문서는 **팀원이** Claude에게 일을 시킬 때 지킬 것이다. Claude가 매번 읽을 필요가 없어서 따로 두었다.

- **세션 하나 = 이슈 하나.** 다른 일을 시작할 때는 `/clear`로 비우거나 새 세션을 연다. 대화가 길어지면 `/compact`.
- 첫 메시지에 **이슈 번호, 묶음, AC ID, 만들 범위**를 적는다. Claude가 그걸 찾느라 문서를 뒤지지 않게 한다.
  > 예: "이슈 #23, 3번 묶음. AC-F3-09~12 견적 내역 확인 카드와 컨펌을 백엔드만 만들어 줘. 화면은 다음에."
- 큰 기능은 **백엔드 → 화면**처럼 나눠서 시킨다. 한 번에 다 시키면 다시 읽는 양이 커진다.
- 간단한 일(문구 수정, 테스트 이름 바꾸기, 작은 버그)은 가벼운 모델로 충분하다. 설계·동시성·결제 계산처럼 어려운 일만 가장 좋은 모델을 쓴다.
- Claude가 규칙과 다르게 하려고 하면 "CLAUDE.md 몇 장 기준으로 다시 해 줘"라고 짚어 준다.
- Claude가 끝에 보여 주는 **검증 표와 "확인 못 한 것"**을 꼭 읽고 PR 설명에 붙인다.
